## 1. 快速上手

目标:做一个"屏幕上出现『开始』按钮就自动点击"的脚本。

**第一步:添加步骤**
在左侧命令工具箱「图色识别」分类中,找到 **🖼 找图点击**,双击它(或点右侧的"＋"按钮),中间步骤树就会出现一个"找图点击 (未选模板) 相似度0.85"的步骤。

**第二步:截取模板图**
选中这个步骤,右侧属性面板点 **🖼 抓模板图**:
- 如果还没保存过脚本,会先弹出保存对话框(模板图需要存放目录),保存到任意文件夹即可;
- 屏幕变暗进入抓图模式,**按住鼠标左键拖出一个框**,框住你要找的目标(比如游戏里的"开始"按钮),松开鼠标即完成;
- 框选时右下角会显示框的大小,移动鼠标时放大镜会显示坐标和颜色;
- 按 **Esc**、点右上角"✕ 取消"或点鼠标右键可放弃抓图。

抓好的模板自动保存为 `templates/tpl_xxxxxx.png`,属性面板会显示缩略图。

**第三步:验证能不能找到**
点属性面板的 **🔍 测试找图**。编辑器立即抓一次屏并匹配:
- 找到 → 日志显示 `✔ 找图成功:(x,y) 相似度 0.98`,屏幕上目标位置出现红框一闪;
- 找不到 → 日志显示 `✖ 找图失败`,见 [FAQ](#11-常见问题-faq) 调整相似度或重新截模板。

**第四步:运行**
- 点工具栏 **▶ 运行** 或按 **F9**:脚本开始循环执行;
- 按 **F10** 或点 **■ 停止** 随时停下;
- 日志区实时打印每一步做了什么。

**第五步:让它更实用**
- 在"找图点击"后面加一个 **⏱ 延时**(方式选"随机",1~2 秒),动作更自然;
- 外面套一个 **🔁 循环**(固定次数或无限),就能持续挂机;
- 点 **💾 保存** 保存脚本,下次「📂 打开」继续编辑。

## 2. 界面总览

```
┌────────────────────────────────────────────────────────────┐
│ 工具栏: 📄新建 📂打开 💾保存 │ ▶运行(F9) ■停止(F10) │ 🐍导出 ⚙设置 │
├──────────┬──────────────────────────────┬──────────────────┤
│ 命令工具箱 │           脚本步骤(树)         │     步骤属性      │

│ 双击/＋添加│  ☑ 🔁 循环 10 次              │  抓图/取色/测试按钮 │
│          │     ├─ ✔ 满足条件时…           │                  │
├──────────┴──────────────────────────────┴──────────────────┤
│ 运行日志(实时输出每步执行情况)                                  │
├────────────────────────────────────────────────────────────┤
│ 状态栏:运行状态 / 工程文件路径                                 │
└────────────────────────────────────────────────────────────┘
```

- **命令工具箱**:17 种积木按"图色识别 / 鼠标键盘 / 流程控制 / 其他"分组。双击或点行尾"＋"添加。添加位置:若当前选中了循环/条件步骤则加进其内部,否则加到选中步骤后面,未选中时加到末尾。
- **脚本步骤树**:
  - 拖动步骤可排序(拖到目标步骤后面,或拖进"满足条件时/否则"分支);
  - 每行最左的 **勾选框** 控制启用/禁用(禁用的步骤运行时直接跳过,但保留在脚本里);
  - **右键菜单**:复制、删除、上移、下移;
  - 运行时当前正在执行的步骤会**橙色高亮**。
- **步骤属性面板**:显示选中步骤的全部参数,改动即时生效。不同步骤类型的参数不同,详见第 3~5 章。
- **运行日志**:带时间戳,格式如 `[14:30:05] ✔ 找到 (720,450) 相似度0.97,单击完成`。
- **状态栏**:左侧为运行状态(就绪/● 运行中),右侧为当前工程文件路径。

## 3. 图色识别

### 3.1 找图点击 ⭐ 最常用

在屏幕上寻找模板图,找到后把鼠标移过去并点击。

| 参数 | 说明 |
|------|------|
| 模板图 | 要找的目标截图,用"抓模板图"截取或"选择图片"导入 |
| 相似度 | 0.5~1.0,默认 **0.85**。匹配不到就调低(0.8、0.75),误匹配/点错就调高(0.9、0.95) |
| 搜索区域 | 默认 full(全屏)。强烈建议框选一个小区域:速度快 10 倍以上,且不会被屏幕其他相似内容干扰 |
| 点击方式 | 单击 / 双击 / 右键 / 不点击(只找不点,常配合判断流程) |
| X偏移 / Y偏移 | 点击位置相对找到目标**中心点**的偏移像素,如目标右半边才能点时就设 offsetX=20 |
| 等待超时(秒) | 在这段时间内每隔"检测间隔"找一次,找到立即执行后续步骤 |
| 检测间隔(秒) | 两次找图之间的间隔,默认 0.5 秒。太小费 CPU,太大反应慢 |
| 超时后 | **继续执行**(跳过这步往下走)或 **停止脚本**(整个脚本结束) |

**执行逻辑**:循环抓屏→找图,直到找到或超时。找到后移动鼠标到目标中心+偏移处,执行点击。

**调优技巧**
- 模板只截目标**本身**(按钮文字、图标),不要带周围背景;
- 目标有动画/闪烁时,截它**静止时的样子**;
- 屏幕缩放/分辨率/游戏画质改变后,旧模板可能失效,需要重新抓;
- 模板是纯色块时编辑器会直接报错提示(纯色块无法用于找图),请改截有文字/图案的部分,或改用「找色点击」。

### 3.2 找色点击

在屏幕上找指定颜色的像素,找到后点击。

| 参数 | 说明 |
|------|------|
| 颜色 | 目标颜色,点"取色"用吸管从屏幕上取,格式 `#RRGGBB` |
| 容差 | 每个颜色通道允许的偏差(0~100),默认 15。抗视频压缩/抗明暗变化,画面有噪点就加大 |
| 其余 | 与找图点击相同(区域/点击方式/偏移/超时/间隔/超时后) |

**适用场景**:纯色按钮、进度条、血条、技能图标底色、小地图标记等颜色固定但形状会变的目标——比找图更快更稳。

### 3.3 等待图出现 / 等待图消失

一直检测到模板出现(或消失)为止,超时后按"超时后"策略处理。典型用途:
- 等待加载界面消失(等待图消失);
- 等待"领取奖励"按钮亮起(等待图出现)。

### 3.4 判断图存在 / 判断色存在

立即检测一次(不等待),根据结果走不同分支:
- **✔ 满足条件时**:树里该步骤下的这个分支会执行;
- **✖ 否则**:另一个分支会执行。

两个分支都可以拖入任意步骤,实现"有怪就打、没怪就挂机"这类逻辑。

## 4. 鼠标键盘

### 4.1 鼠标点击
在指定坐标点击。**X坐标 / Y坐标 = -1 表示当前鼠标位置**(常用于"在找到的位置附近再点一下")。点击方式:单击 / 双击 / 右键。

### 4.2 鼠标移动
把鼠标移到指定坐标。坐标是**屏幕绝对像素**,主显示器左上角为 (0,0)。

### 4.3 滚轮
正数向上滚、负数向下滚,120 约为一格(如 -240 向下两格)。

### 4.4 拖拽
按住左键从起点平滑拖到终点,可设耗时(秒)。用于滑动列表、拖动物品。

### 4.5 按键
| 写法 | 含义 |
|------|------|
| `a` / `5` | 单个字母/数字键 |
| `F5` | 功能键(F1~F24) |
| `space` / `enter` / `esc` / `tab` | 常用键 |
| `up` `down` `left` `right` | 方向键 |
| `home` `end` `pageup` `pagedown` `delete` `insert` | 编辑键 |
| `shift` `ctrl` `alt` `win` | 修饰键 |
| `ctrl+s` | 组合键,用加号连接,先按后放 |
| `numpad0`~`numpad9` | 小键盘数字 |

"重复次数"= 连按几下,"按键间隔"= 两下之间的秒数。

### 4.6 输入文本
以 Unicode 方式逐字输入,**支持中文**,适用于聊天框、搜索框、记事本等标准输入框。
⚠ DirectInput 游戏内部不支持 Unicode 输入,游戏内打字请用「按键」模拟英文/数字,或粘贴方案(暂未内置)。

## 5. 流程控制与其他

| 步骤 | 说明 |
|------|------|
| ⏱ 延时 | 方式"固定"睡指定秒数;"随机"在 [秒数, 上限秒数] 里随机取值,**推荐用随机**,行为更自然 |
| 🔁 循环 | "固定次数"重复 N 遍,"无限循环"一直重复(F10 停止)。把子步骤拖进循环体内即可 |
| ⏏ 跳出循环 | 立即结束**最近一层**循环,继续执行循环后面的步骤。常放在条件分支里实现"完成即停" |
| 💬 注释 | 只写进脚本备查,运行时打印到日志,不做任何动作 |
| 🛑 停止脚本 | 立即结束整个脚本(相当于按 F10) |

## 6. 抓图取色与区域

### 6.1 抓模板图
1. 属性面板点「🖼 抓模板图」(未保存工程会先让你保存脚本);
2. 屏幕变暗,按住左键拖框,松开完成;Esc / 右键 / ✕ 按钮取消;
3. 放大镜实时显示:坐标(屏幕绝对像素)、RGB、`#RRGGBB`;
4. 模板自动存到工程目录的 `templates/` 文件夹,并填入参数。

**好模板的标准**:小而独特。只截按钮/图标本身;包含文字或边框等细节;别把整块背景截进去。

### 6.2 取色
属性里点「取色」→ 移动鼠标看放大镜 → 单击即取该点颜色。找色的"容差"建议 10~30。

### 6.3 框选区域
点「⬚ 框选区域」拖出矩形,或手填 `x,y,w,h`(屏幕绝对像素),点「全屏」恢复全屏搜索。
**为什么建议用区域**:全屏 1080p 找一次图约几十毫秒,限制到 200×200 的区域后只需 1~2 毫秒;同时避免屏幕别处的相似按钮被误点。

## 7. 运行与调试

- **F9 运行 / F10 停止**:全局热键,游戏全屏时也有效;工具栏按钮等价。
- **当前步骤高亮**:运行中,正在执行的步骤在树里橙色显示,一眼看出卡在哪。
- **日志**:每步都记录,包含找到的坐标、相似度、延时长度等;出问题先看日志最后一行。
- **失败策略**:每个图色步骤都有"超时后:继续执行 / 停止脚本"。挂机脚本一般选"继续执行",关键步骤(如进入副本)可设"停止脚本"防止瞎点。
- **整体循环**:「⚙ 设置」→ 脚本整体循环次数。0 = 无限循环(从第一 步到最后一步反复跑)。

## 8. 设置窗口详解

| 设置项 | 选项与说明 |
|--------|-----------|
| 抓图引擎 | **自动**(推荐):先试 DXGI,失败/黑屏自动转 GDI;**仅 DXGI**:强制桌面复制,适合 DirectX 网游;**仅 GDI**:最保守,兼容普通窗口,独占全屏游戏可能黑屏 |
| 键盘扫描码模式 | 开(默认):键盘以扫描码发送,兼容 DirectInput 类游戏;关:以虚拟键码发送,兼容性稍差但更"标准"。一般保持开启 |
| 脚本整体循环次数 | 整个脚本从头到尾跑几轮,0 = 无限 |
| 热键 | 当前版本固定 F9=运行、F10=停止(界面有提示) |

## 9. 导出 Python

点工具栏「🐍 导出 Python」,选一个 .py 文件名,编辑器会把积木脚本**编译成带缩进的可读 Python 代码**,并复制所有模板图到同目录 `templates/` 下,同时生成《运行说明.txt》。

目标机器只需安装 Python 3.8+:

```bash
pip install opencv-python mss numpy pydirectinput
python script.py
```

- 停止:命令行按 Ctrl+C;
- 模板图必须与 script.py 保持 `templates/` 的相对位置;
- 导出脚本同样是前台模拟输入,协议与风险同编辑器内运行。

## 10. 网游适配指南

| 环节 | 方案 |
|------|------|
| 抓图 | DXGI 桌面复制:可抓 DX9~DX12 游戏的窗口化/无边框/全屏画面;失败或全黑自动降级 GDI |
| 输入 | SendInput 硬件级模拟;键盘默认扫描码模式,兼容 DirectInput 游戏 |
| 坐标 | 全程物理像素,PerMonitorV2 DPI 感知,高 DPI 屏不偏移 |

**建议的游戏设置**:窗口化或无边框窗口(不要独占全屏),这样抓图兼容性最好。

**重要边界**
1. 本工具为**前台**自动化,操作的是当前活动窗口,不支持后台多开;
2. **不做内核驱动注入,不做任何反反作弊规避**;
3. 装有强反作弊的游戏(腾讯 ACE/TP、EAC、BattlEye 等)可能拦截模拟输入或屏蔽截图——表现就是"点了没反应"或"截图全黑",这是反作弊在起作用,不是 bug;
4. 网游中使用脚本通常违反用户协议,**有封号风险**,请自行评估;建议仅用于单机游戏、自己写的程序或工作自动化。

## 11. 常见问题 FAQ

**Q1:测试找图总是失败?**
按顺序排查:① 相似度调低到 0.8 试试;② 模板是不是带了大片背景/跨了缩放,重新抓一个更小更独特的;③ 屏幕分辨率或游戏画质(亮度、特效、HDR)是否和截模板时不同;④ 用「框选区域」把搜索范围对准目标附近;⑤ 目标是纯色块的话改用「找色点击」。

**Q2:截图全黑?**
设置里把抓图引擎切到「仅 GDI」试试;游戏改窗口化/无边框;确认没有被 OBS 等采集软件占用桌面复制。日志会写明当前用的引擎与降级原因。

**Q3:找到了也点了,但游戏没反应?**
① 游戏带反作弊拦截了模拟输入(见第 10 章);② 目标窗口需要管理员权限——**以管理员身份运行编辑器**;③ 有些游戏要求先点击窗口获得焦点,在脚本开头加一个「鼠标点击」(点游戏窗口任意处)。

**Q4:输入文本中文进不去?**
输入文本走 Unicode,只在标准输入框(聊天框、编辑器、网页)有效;游戏内 DirectInput 不支持,请用「按键」输入英文数字。

**Q5:鼠标乱点/位置不对?**
确认屏幕缩放没有在脚本运行中途改变;坐标是屏幕绝对像素(主显示器左上角为 0,0),重抓模板即可自动对齐,不要手抄别的设备的坐标。

**Q6:F9 没反应?**
热键可能被其他软件(输入法、录屏、游戏内按键)占用,关闭冲突软件后重启编辑器。

**Q7:运行很卡/CPU 高?**
① 用「框选区域」缩小搜索范围;② 加大"检测间隔"(0.5 秒足够);③ 能用找色就别找图。

**Q8:多显示器能用吗?**
能。抓图覆盖主显示器;找图/找色覆盖整个虚拟桌面(多屏都会搜),点击坐标自动换算。建议把游戏放主显示器。
