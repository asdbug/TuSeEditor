# 2026-08-31

## 修复:属性面板所有下拉框(Combo)候选项为空
- 现象:工具箱添加任意步骤后,右侧属性面板的"方式"(延时/循环)、"点击方式"、"超时后"下拉条全是空白,无内容可选。
- 根因:`MainWindow.xaml` 中 ComboRowVM 模板写 `ItemsSource="{Binding Options}"`,但 `PropertyRowVM` 没有 `Options` 属性;候选项只在 `Def.Options`,且 `Def` 原来是 public **字段**(WPF 无法绑定字段),绑定静默失败 → 空列表。
- 修改:
  - `ViewModels/PropertyRows.cs`:`Def` 字段改为属性并在 setter 中通知 `Label`/`Options`;新增 `public string[] Options => Def.Options`;新增 `virtual void NormalizeValue()`;`ComboRowVM` 重写它,值不在候选项内时回退首项(防旧工程脏值再次导致空白)。
  - `ViewModels/MainViewModel.cs`:`BuildPropertyRows()` 中设置 `row.Value` 后调用 `row.NormalizeValue()`。
  - `MainWindow.xaml`:Combo 模板补 `Visibility="{Binding IsVisible, Converter={StaticResource Bool2Vis}}"`(与其它行模板一致)、MinWidth/边框样式。
- 验证:`dotnet build src/TuSeEditor.App/TuSeEditor.App.csproj -c Debug` 通过(0 错误;Converters.cs 的 4 个 null 警告为既有问题,未改动)。

### 经验
- 本项目属性面板是"隐式 DataTemplate + VM 子类"驱动,新增 VM 属性后必须确认 XAML 绑定名在 VM 上真实存在;WPF 绑定失败不报错,只表现为空白,调试时优先核对绑定路径。
