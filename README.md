# 图色脚本编辑器(TuSeEditor)

一个 PC 端**图色脚本编辑器**:像按键精灵一样,用可视化积木搭建"找图点击 / 找色点击 / 循环 / 延时"等自动化脚本,支持一键运行调试(全局热键 F9/F10),并可**导出为独立 Python 脚本**脱离编辑器运行。

> 开发栈:C# WPF(.NET 8)+ OpenCvSharp(模板匹配)+ DXGI 桌面复制 / GDI 抓图 + SendInput 模拟输入

---

## 功能一览

### 可视化编辑
- 左侧**命令工具箱**(按图色识别 / 鼠标键盘 / 流程控制 / 其他 分组),双击或点"＋"添加步骤
- 中间**步骤树**:拖动排序、勾选启用/禁用、右键复制/删除/上移/下移,循环与条件步骤有可嵌套的子分支
- 右侧**动态属性面板**:根据步骤类型自动生成参数表单
- 底部**运行日志**实时输出每一步的执行情况

### 17 种积木命令
| 分类 | 命令 |
|------|------|
| 图色识别 | 找图点击、找色点击、等待图出现、等待图消失、判断图存在(是/否分支)、判断色存在(是/否分支) |
| 鼠标键盘 | 鼠标点击(单/双/右)、鼠标移动、滚轮、拖拽、按键(单键/组合键如 ctrl+s)、输入文本(Unicode,支持中文) |
| 流程控制 | 延时(固定/随机)、循环(固定次数/无限)、跳出循环 |
| 其他 | 注释、停止脚本 |

### 抓图 / 取色
- **抓模板图**:全屏截图覆盖层,拖动框选目标,自带像素级放大镜(显示坐标 + RGB + 十六进制色值),自动保存到工程的 `templates/` 目录
- **取色**:覆盖层单击取色,自动填入颜色参数
- **框选区域**:为找图/找色限定搜索范围(区域越小越快,坐标为屏幕绝对像素)
- **测试找图/找色**:立即抓屏匹配一次,成功时在屏幕上画红框标出位置

### 运行与调试
- 全局热键:**F9 运行 / F10 停止**(任何前台程序下都有效)
- 后台线程执行,当前步骤在树中橙色高亮
- 每步可设置:超时时间、检测间隔、失败策略(继续执行 / 停止脚本)
- 整体循环次数可设(含无限循环)

### 导出 Python
- 把积木树编译成**带缩进的可读 Python 脚本**(内嵌找图/找色/点击引擎),连同模板图一起导出
- 运行导出脚本只需:`pip install opencv-python mss numpy pydirectinput` 后 `python script.py`

## 网游适配说明(重要)

| 环节 | 方案 | 说明 |
|------|------|------|
| 抓图 | **DXGI 桌面复制优先,失败/黑屏自动降级 GDI** | DXGI 可抓取 DX9~DX12 游戏的窗口化/无边框画面;GDI 兼容普通窗口但独占全屏游戏可能黑屏 |
| 输入 | SendInput,键盘默认**扫描码模式** | 兼容 DirectInput 类游戏;设置里可切换虚拟键码模式 |
| 坐标 | 全程物理像素(PerMonitorV2 DPI 感知) | 多显示器下点击坐标自动换算 |

**能力边界(请务必了解):**
1. 本工具是**前台**自动化(操作当前活动窗口),不含后台多开;
2. **不做内核驱动注入、不做任何反反作弊规避**。带强反作弊的游戏(腾讯 ACE/TP、EAC、BattlEye 等)可能拦截 SendInput 或屏蔽截图,此类游戏不保证可用;
3. 在网游中使用脚本通常**违反用户协议,有封号风险**,请自行评估并仅在自己拥有权限的环境中使用;
4. 一个输出同一时刻只能有一个 DXGI 复制占用者(如 OBS 之类采集软件正在占用时会自动降级 GDI)。

## 构建与运行

需要 Windows 10/11 与 [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0)。

```bash
# 还原 + 构建
dotnet build TuSeEditor.sln

# 运行编辑器
dotnet run --project src/TuSeEditor.App

# 运行核心服务无头自检(抓图/找图/找色/输入/导出/引擎)
dotnet run --project tests/TuSeEditor.TestCore

# 发布单文件版(可选)
dotnet publish src/TuSeEditor.App -c Release -r win-x64 --self-contained ^
  -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract -o publish
```

## 使用流程

1. 左侧工具箱添加「找图点击」→ 右侧点「🖼 抓模板图」框选要找的按钮 → 需要时点「🔍 测试找图」验证;
2. 继续添加「延时」「循环」等步骤,拖动排列顺序,勾选/取消勾选控制启用;
3. 按 **F9** 运行,**F10** 随时停止;
4. 「⚙ 设置」里可切换抓图引擎(自动/DXGI/GDI)、键盘扫描码模式、整体循环次数;
5. 「🐍 导出 Python」生成独立脚本,可在没装本编辑器的机器上运行。

## 工程文件

- 脚本保存为 `.tsproj`(JSON 格式,含全部步骤与参数),模板图存放在同目录 `templates/` 文件夹;
- 编辑器设置保存在 `%APPDATA%\TuSeEditor\settings.json`。
